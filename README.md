# Clockwork Conservatory support site

Official static player support and privacy site. Game source is maintained separately in a private repository.

- Website: https://truesolutionsllc.github.io/clockwork-conservatory-site/
- Support: https://truesolutionsllc.github.io/clockwork-conservatory-site/support.html
- Privacy: https://truesolutionsllc.github.io/clockwork-conservatory-site/privacy.html

GitHub Pages publishes `docs/` from `main`. No build dependencies, analytics, JavaScript or external fonts. To preview: `python3 -m http.server 8080 --directory docs`.

Artwork is project environment artwork, optimized for the web. Copyright TrueSolutionsLLC; no open source license is granted to game artwork or branding.
